# ТикТокер

Новый самостоятельный проект конвейера Twitch → вертикальные ролики → проверка
пользователем → публикация → статистика. Название проекта: ТикТокер (tiktoker).
Корень проекта: `E:\Projects\tiktoker`.

ClipFlow-Studio используется только как визуальный референс. Его код,
редактор, конфигурация и интеграции не являются основой этого проекта.
Для подключения используется новое Twitch-приложение пользователя.

## Текущее состояние

Работают обнаружение клипов, подготовка исходников, вертикальный монтаж и
локальные автосубтитры. Готовые ролики пользователь проверяет в редакторе.

## Что уже написано

Есть сборщик через Helix и локальная панель: каналы, лента клипов, поиск,
фильтры, встроенный Twitch-плеер, отбор/отклонение, управление наблюдением.
Отбор сохраняется между перезапусками. Новые ключи успешно проверены.
Обнаружение новых клипов подтверждено на shadowkekw; устранение дублей на
живом контенте ещё не подтверждено — у большинства клипов нет таймкодов VOD.
Теперь реализована подготовка исходников: скачивание публичных клипов,
совместимый видеопредпросмотр, постоянная очередь, подготовка одобренных клипов
и проверка похожих моментов по видео/звуку. Один уникальный клип — отдельная задача.
Реализован вертикальный MP4 1080×1920 с вебкой сверху, основным кадром снизу
и заголовком между ними. Редактор позволяет менять границы, области кадра,
высоту вебки и заголовок. Версии рендера, одобрение и отклонение сохраняются.
Для shadowkekw задана левая вебка с темноволосым стримером. Для IRL-эфиров
ravshann задан квадратный кадр по центру с размытым фоном из того же исходника.
Автоматический монтаж запускается после одобрения клипа и подготовки исходника.
По умолчанию монтаж создаётся без субтитров. Галочка «Сделать субтитры» запускает
локальное распознавание русской речи через Whisper для выбранного ролика.
Субтитры показывают по 2–3 слова с подсветкой произносимого слова. В редакторе
можно исправить или убрать слова, изменить их таймкоды, размер и положение текста.
После правок создаётся новая версия MP4. Публикация и статистика ещё не реализованы.

## Запуск

Используется Node.js 22+. Для этого компьютера в `.runtime/node.exe` подготовлена
локальная копия Node.js из установленного runtime Codex. Файл запуска сначала
использует её, затем ищет Node.js в PATH. Системная установка не требуется.
`.runtime/` исключён из Git; на другом компьютере понадобится Node.js 22+
или локальный runtime. Внешних npm-зависимостей пока нет.

Для автосубтитров нужны `whisper-cli.exe` и многоязычная модель Whisper small.
На этом компьютере они уже находятся в `.runtime/`. Для нового компьютера
запусти `powershell -ExecutionPolicy Bypass -File tools/install-asr.ps1` в папке
проекта. Скрипт загрузит модель примерно 488 МБ из официального репозитория.

1. Ключи хранятся в `output/.secrets/twitch.json`.
2. Запустить `start_tiktoker.cmd` или `node src/server.mjs`.
3. Открыть http://127.0.0.1:4317. По умолчанию выбран ravshann;
   leva2k и shadowkekw доступны в списке каналов.
4. Нажать «Начать наблюдение». Оно длится до 4 часов или остановки.
   «Обновить сейчас» запускает внеочередной опрос Twitch и показывает, сколько
   новых клипов пришло. Лента сортируется по времени создания: новые сверху.
5. Во вкладке «Новые клипы» посмотри момент и нажми «Одобрить клип» или
   «Отклонить». До одобрения автоматическая подготовка не начинается.
6. Открой вкладку «Монтаж и проверка». Одобренный клип появится в очереди:
   исходник подготовится, похожие моменты попросят решения, затем автоматически
   создастся вертикальный MP4.
7. Готовое видео просматривается прямо в этой вкладке. Правки композиции
   видны сразу; «Создать новую версию» экспортирует их в MP4 для окончательной
   проверки. Монтаж можно одобрить, отклонить или скачать. Это пока не публикация.

Во вкладке «Анализ эфира» вставь ссылку на Twitch VOD или канал. Для канала
берётся текущий эфир, а если он закончен — последняя доступная запись.
Клипы группируются по таймкоду исходного эфира (близкие начала или сильно
пересекающиеся интервалы) и сортируются по просмотрам лидера группы.
Внутри группы клипы тоже отсортированы по просмотрам. Порог «Минимум
просмотров» фильтрует отдельные клипы; по умолчанию — 10. Если Twitch ещё не
вернул таймкод, группировка по времени создания помечается приблизительной.

Проверки: `node --test tests/*.test.mjs`.
Сборщик без интерфейса: `npm run watch:shadowkekw` / `npm run watch:ravshann` /
`npm run watch:leva2k`.
Управлять остановкой через панель можно только для процесса, запущенного ею.
Закрытие сервера останавливает запущенные им сборщики.

Панель слушает только loopback. Не публикуйте её в интернет без разработки
аутентификации. Ключи не выдаются HTTP-сервером. Воспроизведение Twitch требует
сети и может быть ограничено настройками браузера — есть ссылка на оригинал.

Отчёт о проверке: [docs/TEST-REPORT-2026-11-15.md](docs/TEST-REPORT-2026-11-15.md).

Секреты не отправлять в чат и не коммитить. Старые приложения и токены
не используются автоматически. Сборщик читает только явно указанный файл
либо переменные TWITCH_CLIENT_ID и TWITCH_CLIENT_SECRET.

Подробности и ограничения: [docs/clip-observer.md](docs/clip-observer.md).
