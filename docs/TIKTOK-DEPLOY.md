# TikTok Direct Post: текущая интеграция

Сайт: `https://tiktok.ravshan.tv`; защищённая студия: `https://tiktok.ravshan.tv/studio`.

## Что готово

- После одобрения MP4 и описания в монтаже можно подключить TikTok по Login Kit, запросить актуальные настройки аккаунта, выбрать видимость и явно отправить видео через Direct Post.
- Сервер использует `PULL_FROM_URL`: TikTok забирает одобренный MP4 по временной подписанной HTTPS-ссылке. Ссылка не требует входа в студию, действует 24 часа и перестаёт работать при снятии одобрения.
- Client Secret, токены OAuth и ключ подписи лежат только в `output/.secrets/`, вне Git. Ответы API не содержат секретов. Повторная отправка одной версии блокируется. Статус публикации можно обновить кнопкой.
- Публичные `/terms` и `/privacy` доступны без пароля для проверки приложения.

## Настройка в TikTok Developer Portal

1. Выбрать платформу **Web**. В Login Kit включить **Configure for Web** и добавить точный Redirect URI: `https://tiktok.ravshan.tv/tiktok/callback`.
2. В Content Posting API оставить включённым **Direct Post** и scope `video.publish`. `video.upload` можно исключить из заявки, если черновики не используются.
3. В **URL properties / Verify domains** подтвердить `tiktok.ravshan.tv` для `PULL_FROM_URL`. Способ подтверждения укажет портал. Если нужен файл или DNS TXT, выполнить именно выданное им действие.
4. В студии открыть любой готовый монтаж, раскрыть **Настроить приложение TikTok**, вставить Client Key и Client Secret. Делать это только через HTTPS-страницу; в чат и Git секреты не отправлять.
5. Нажать **Подключить TikTok-аккаунт**, разрешить `user.info.basic` и `video.publish`, затем **Проверить аккаунт и настройки публикации**.
6. Для ревью снять демонстрацию полного пути: одобрение монтажа → описание → подключение аккаунта → выбор видимости → явная публикация → статус. TikTok требует видео демо и проверку приложения для публичной видимости; без аудита Direct Post ограничен приватной публикацией.

Локальный код и сервер не могут выдать доступ `video.publish` или снять приватный лимит: это делает TikTok при настройке и ревью приложения. Лимиты публикаций устанавливаются TikTok на конкретный аккаунт и могут не допустить 50 роликов в сутки с одного аккаунта.

Важно: для ревью потребуется показать работающий сайт с подходящим доступом рецензенту. Не выдавать пароль root от VPS в качестве демо-доступа; перед заявкой создать отдельный вход для ревью.

Документация TikTok: [Web Login Kit](https://developers.tiktok.com/docs/en/login-kit-web), [Direct Post](https://developers.tiktok.com/docs/en/content-posting-api-reference-direct-post), [Content Sharing Guidelines](https://developers.tiktok.com/docs/en/content-sharing-guidelines).
