# Отчёт первой разработки и проверки — 15 ноября 2026

Все часы ниже — московское время (UTC+3).

## Что реализовано

- Сборщик Helix с сохранением клипов и повторными опросами.
- Журнал событий events.jsonl, повтор после ошибок опроса, обновление статуса эфира.
- Защита от одновременной записи двумя сборщиками через lock-файл.
- Различение исходной исторической выборки, поздней догрузки старых клипов
  и клипов, созданных после начала наблюдения.
- Локальный сервер и панель на http://127.0.0.1:4317.
- Каналы shadowkekw/ravshann, поиск, фильтры, миниатюры и встроенный Twitch-плеер.
- Ручной отбор и отклонение исходников с сохранением между перезапусками.
- Запуск/остановка наблюдения из панели; остановка доступна только для её процессов.
- Запуск через start_tiktoker.cmd или node src/server.mjs.

Панель первого этапа написана на HTML/CSS/JS без зависимостей. Это осознанное
сокращение объёма для проверки сбора, не готовый видеоредактор. React/SQLite
из ТЗ пока не внедрены. Исходники и решения хранятся в локальных JSON.

## Автоматические проверки

`node --test tests/*.test.mjs`: **10 тестов прошли**.

- Группировка пересекающихся клипов; разделение соседних событий/разных VOD.
- Защита от цепочки пересечений, корректность нулевого и отсутствующего offset.
- Уникальность clip_id и сохранение first_seen_at после сериализации.
- Различение baseline, новых и поздно индексированных старых клипов.
- Блокировка второго сборщика.
- Сервер: чтение состояния, сохранение отбора и восстановление после перезапуска.
- Отказ запросам с чужим Origin, без служебного заголовка, с неверным каналом/ID.
- HTTP не выдаёт файл секретов. Проверено исключение ключей из Git.

Также выполнена проверка синтаксиса JS. Тесты сервера используют временные
фикстуры, а не меняют реальные решения пользователя по клипам.

  не выполнены; обход запрета не предпринимался.
- 38/39 клипов без таймкодов: автоматическое устранение дублей на живом
  контенте НЕ подтверждено. В панели это явно обозначено.
- Скачивание исходников, аудио/видеосопоставление, смысловой выбор границ,
  автоопределение камеры, рендер и субтитры пока отсутствуют.

- ravshann в этой сессии не тестировался.
- Нагрузка 50 роликов/сутки ещё не измерялась.
