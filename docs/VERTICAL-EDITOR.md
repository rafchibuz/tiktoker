# Вертикальный монтаж

## Что работает

Один одобренный и подготовленный Twitch-клип создаёт отдельную задачу
монтажа. FFmpeg выпускает MP4 1080×1920, H.264/AAC. В режиме «вебка сверху»
верхний блок берётся из выбранной области горизонтального кадра, нижний — из
области действия. Заголовок по умолчанию расположен у стыка с вебкой поверх
нижнего кадра. Он набран Komika Title Axis RUS-LAT, с чёрной обводкой. Подложка
чёрная, 30% непрозрачности, на всю ширину 1080 px и по высоте текста. Её можно
отключить или двигать по вертикали вместе с текстом. Текст можно отдельно
смещать по горизонтали и вертикали. Есть режим одного кадра.

Первый этап находится на главной странице: пользователь одобряет или отклоняет
только что созданный клип. Одобрение запускает подготовку и автоматический
монтаж. Вкладка `/montage` показывает все одобренные клипы и готовые MP4.
Исходник открывается отдельной кнопкой; в центре просмотра находится готовый
вертикальный ролик. Можно менять начало и конец в пределах исходника,
заголовок, положение и размер обеих областей, высоту вебки и способ заполнения
нижнего блока. При правке тот же блок просмотра показывает композицию сразу;
новый MP4 создаётся отдельной кнопкой. «Сохранить черновик» сохраняет
настройки только этого ролика, не изменяя MP4. «Сохранить шаблон канала»
сохраняет также текущий черновик и переносит геометрию на будущие одобренные
клипы этого канала. Оба действия показывают подтверждение. При смене рецепта
прежнее одобрение снимается; старую версию нельзя одобрить заново.
Результат сохраняется как новая версия, доступная для просмотра и скачивания.
Предпросмотр на странице ограничен шириной 300 пикселей и высотой окна.
В браузере для исходника используется совместимый предпросмотр. Он может быть
уменьшен до 1280 пикселей; финальный рендер берёт сохранённый исходный файл.
Пример исходника — 2560×1440 HEVC. Экспорт — 1080×1920 H.264/AAC, поэтому
это новое кодирование, а не побитная копия Twitch-клипа.

Для shadowkekw профиль по умолчанию использует левую вебку с темноволосым
стримером, выбранную пользователем. «Сохранить шаблон канала» сохраняет геометрию.
Для IRL-эфира ravshann начальный шаблон использует квадратный основной кадр
900×900 по центру 1080×1920. Квадрат и размытый фон берутся из одного исходника.
В редакторе меняются размер, положение квадрата и область изображения внутри
него. Заголовок стоит сверху; нижняя часть фона оставлена для будущих субтитров.
Сохранённый пользователем профиль канала имеет приоритет над этим шаблоном.
Автоматический рендер относится только к клипам, одобренным пользователем на
первом этапе. Он не публикует ролики и не одобряет монтаж.

## Проверка 15 ноября 2026

Из реального исходника shadowkekw создан восьмисекундный ролик. `ffprobe`
подтвердил 1080×1920, 8 секунд, H.264/AAC. HTTP выдача поддерживает Range;
проверен ответ 206 на первые 1024 байта. 28 автоматических тестов прошли,
включая создание версий, восстановление после перезапуска и запрет одобрения
устаревшего или отклонённого исходника. Визуально проверен кадр тестового
рендера; браузерная проверка кликов пока не проводилась.

## Следующие задачи

1. Распознать речь с временем каждого слова и сделать два режима субтитров.
2. Добавить правку текста субтитров и описания перед одобрением.
3. Подключить уведомление о готовности и разрешённый способ публикации TikTok.
4. Измерить время обработки и устойчивость на нескольких клипах.

Текущая JSON-очередь рассчитана на локальную бету. Перед масштабированием до
50 роликов в день понадобятся SQLite, квоты хранилища и нагрузочная проверка.

Файл шрифта загружен из каталога [FFont](https://ffont.ru/en/font/komika-title-axis-rus-lat).
Каталог одновременно указывает на свободное использование и содержит пометку
автора «All rights reserved»; перед коммерческим распространением роликов
следует уточнить лицензию у правообладателя. Шрифт субтитров будет тем же,
но меньшего размера.
