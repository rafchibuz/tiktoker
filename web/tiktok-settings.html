Подключение TikTok.

Сначала проверь Sandbox. Production настраивается отдельно.

Режим

Проверяем подключение…

Redirect URI для Login Kit: https://tiktok.ravshan.tv/tiktok/callback

Ключи приложения

Возьми Client Key и Client Secret именно из выбранного окружения TikTok Developer Portal. Они сохраняются только на сервере.

Аккаунт

Для Sandbox сначала добавь свой TikTok-аккаунт в Target users и нажми Apply changes в портале.

Подключить TikTok через OAuth

Дальше

После подключения выбери клип во вкладке «Новые клипы», одобри монтаж и отправь его в TikTok из редактора. В Sandbox доступна только видимость «Только я».
